# Proyecto WhatsApp AgentKit

El archivo completo de entrenamiento del agente está guardado en CLAUDE_FULL_AGENT.md.

Trabaja sin cargar todo el contexto completo. Usa este proyecto para construir un agente de WhatsApp para empresas.

Objetivo:
- Responder clientes.
- Calificar prospectos.
- Capturar datos.
- Escalar a humano.
- Ayudar a vender servicios de IA, páginas web y automatizaciones.
